# Spektralab 免費 skill：用公開資料看品牌

給電商老闆用的 AI skill。告訴 AI 你的品牌和想比較的品牌，它會自己去查公開資料，在對話裡直接畫出報告。

全程不登入任何帳號，不用付費工具，不碰你平常用的瀏覽器。

## 目前有的 skill

### 搜尋趨勢秒查（`spektralab-trends-free`）

看兩個品牌過去五年在 Google 的搜尋聲量，大約 5 分鐘。報告會告訴你：

- 五年來誰高誰低，有沒有換過位置
- 差距在拉開還是收斂（每一年的平均並排給你看）
- 高峰落在什麼時候，是每年固定的檔期，還是單次事件
- 近一年大家搜這個品牌時，還一起搜什麼

只想看自己的品牌也可以，不一定要比。

其他 skill（Google 廣告、FB IG 廣告、公司登記、一次全查的競品秒查）還在測試，之後會陸續加進來。

## 哪裡能用

這支 skill 需要 AI 有一個自己的瀏覽器，能打開網頁讀數字。

| 環境 | 能不能用 |
|---|---|
| Claude 桌面版（Cowork、Code） | 可以 |
| Codex 桌面版（ChatGPT 桌面 App 裡的 Codex） | 可以 |
| ChatGPT、Gemini、Claude 網頁版或手機版的一般對話 | 不行，AI 會告訴你做不到 |

## 怎麼裝

先下載：按這一頁上方綠色的 Code，選 Download ZIP，解壓縮。要用的是裡面的 `skills/spektralab-trends-free` 這個資料夾。

**Claude 桌面版**：把 `spektralab-trends-free` 資料夾壓成 ZIP，到設定頁的 Skills 上傳。

**Codex**：把 `spektralab-trends-free` 資料夾放進 `~/.codex/skills/`，重開 Codex。

**Claude Code**：把資料夾放進 `~/.claude/skills/`。

資料夾裡有兩樣東西：`SKILL.md` 是做法，`assets/report-template.html` 是報告的版面。兩個都要在。

## 不想裝，直接貼

`paste/spektralab-trends-free.md` 是單檔版。打開檔案、全選複製、貼進 AI 對話就能用。一樣要在上面列的可用環境裡。

## 怎麼用

裝好之後，跟 AI 說「用搜尋趨勢秒查」。它只會問兩件事：

```
a. 你的品牌是？
b. 你想跟哪個品牌比？
```

回答完它就自己跑，報告會直接出現在對話裡。裝成 skill 的版本還會在工作資料夾存一份 HTML，電腦上有 Chrome 的話再加一份 PDF。貼上版要說「存檔」才會存。

## 報告能告訴你什麼，不能告訴你什麼

看得到：搜尋聲量的走勢和相對高低。

看不到：銷量、實際的搜尋次數。圖上的數字是相對值，最高的那一週是 100。搜尋熱度高不代表賣得好。

數字是 0 的那幾週，代表搜尋量低到 Google 不顯示，不是沒人搜。品牌的搜尋量很小時，報告能看出的東西有限。

報告裡的事實和推論是分開寫的，推論會標「未經驗證」。

## 已知限制

這支 skill 讀的是 Google 搜尋趨勢的舊版頁面。Google 已經預告舊版會停用，而新版要登入帳號才看得到。舊版關閉之後，這支 skill 會停止運作，需要等更新。
